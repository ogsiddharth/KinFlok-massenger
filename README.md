# Kinfolk • Private Family Messenger (Web Application)

Kinfolk is a private, lightweight, distraction-free family messaging web application. Built for trusted family circles—connecting family members with zero phone numbers, zero stranger discovery, invitation-only onboarding, real-time messaging, rich media sharing, screenshot privacy controls, an owner administration dashboard, and an integrated Google Gemini AI Help Assistant.

---

## 🌟 Features

### 1. Privacy-First Authentication & Onboarding
- **Zero Phone Numbers**: Accounts use unique usernames, passwords, and single-use invitation codes.
- **Owner Bootstrap Flow**: First-run guided setup for the family space owner. Upon creation, an emergency recovery code (`KIN-XXXX-YYYY`) and an instant 7-day invitation code (`KIN-XXXX`) are generated for the first family member.
- **Invite-Only Registration**: New members can only join using a valid invitation code generated by the family owner.
- **Account Recovery**: Emergency 12-character recovery key (`KIN-XXXX-YYYY`) enables password resets without email or SMS.

### 2. Real-Time Family Chat
- **Instant Messaging**: Real-time conversation stream with auto-scrolling, date separators, sent vs. received bubble styling, and read receipts (`✓` / `✓✓`).
- **Emoji Reactions**: React with 👍, ❤️, 😂, 😮, 😢, 🙏 with counters and active toggles.
- **Replies & Quotes**: Quoted reply snippets attached directly to messages.
- **Message Editing & Deletion**: Edit own messages with an `(edited)` indicator; delete own messages.
- **Pinned Messages**: Pin important family messages to the top banner for instant reference.
- **Live Typing & Presence**: Dynamic "typing..." indicator and "Active now" / "Last seen" statuses.
- **In-Chat Search**: Instant search filtering across all conversation messages.

### 3. Media & Voice Sharing
- **Voice Memos**: Record voice messages directly in the browser using the Web MediaRecorder API with a live recording timer, wave indicator, cancel/send controls, and in-bubble audio playback with a seekable scrubber.
- **Photo Sharing**: Inline photo previews with a full-screen lightbox modal for viewing and downloading.
- **Document Attachments**: Safe file sharing for PDFs and documents with file size and type validation.

### 4. Screenshot Detection & Privacy Controls
- **Screenshot Notification**: Broadcasts a system alert (`⚠️ [Name] took a screenshot`) into the chat when a print-screen or screen-capture shortcut is detected.
- **Strict Privacy Mode**: Toggle in settings to block text selection and blur the chat window when browser focus is lost.
- **Customizable Visibility**: Toggles for Last Seen, Online Status, Read Receipts, and Typing Indicators.

### 5. Owner Administration Dashboard
- **Overview Metrics**: Total members, active online sessions, active invitations, and audit log events.
- **Invitation Manager**: Generate new single-use invite codes with custom expiration (1 day, 7 days, 30 days), copy codes, and revoke active codes.
- **Member Management**: Inspect registered members, roles, and lock/unlock accounts.
- **Security Audit Log**: Complete history of account creation, invitations, logins, and administrative actions.

### 6. Integrated Gemini AI Help Assistant
- **Private In-App Guide**: Accessible via the top bar "AI Guide" button.
- **Zero Chat Access Guarantee**: The AI assistant only answers questions about app settings and features. It has zero access to private family chat conversations.
- **Quick Question Chips & Free-Form Chat**: Instant help on invitations, screenshot alerts, voice memos, and recovery.
- **Secure Netlify Function**: Server-side API requests via `/.netlify/functions/gemini-assistant` to keep `GEMINI_API_KEY` hidden from the client browser.

## 🛠️ Tech Stack & Architecture

- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS, Lucide Icons, Canvas Confetti
- **Serverless Backend**: Netlify Functions (v2), `@google/generative-ai` SDK
- **Database & Storage**: Dual-Engine Architecture
  - **Live Cloud Engine**: Firebase Firestore & Firebase Web SDK v10/v11
  - **Local Persistence Engine**: IndexedDB / LocalStorage with BroadcastChannel for instant multi-tab real-time sync without requiring immediate Firebase configuration.

## 🚀 Running Locally

### Prerequisites
- Node.js 18+ (Node v20+ recommended)
- npm (installed with Node.js)

### Steps

1. **Clone or Navigate to the Workspace**:
   ```bash
   cd massenger
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Configure Environment Variables**:
   Copy `.env.example` to `.env`:
   ```bash
   cp .env.example .env
   ```
   Add your Google Gemini API key:
   ```env
   GEMINI_API_KEY=your_actual_gemini_api_key
   ```
   *(Optional)* If connecting to your Firebase project, provide your Firebase Web SDK credentials. If left empty, the application runs in local multi-tab sync mode!

4. **Start the Development Server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

5. **Test Multi-Tab Real-Time Family Chat**:
   - Tab 1: Click "Initialize Family Space" to create the Owner account (e.g. `@alex`). Copy the Sister invite code.
   - Tab 2 (or Incognito window): Open [http://localhost:5173](http://localhost:5173), click "Join with Invitation Code", enter the invite code, and create the Sister account (e.g. `@maya`).
   - Chat in real-time, record voice memos, share images, react with emojis, and test the Admin Panel!

## ☁️ Deploying on Netlify

### Method 1: Git Integration (Recommended)

1. **Push your code to a Git repository** (GitHub, GitLab, or Bitbucket).
2. Log in to [Netlify](https://app.netlify.com).
3. Click **Add new site** > **Import an existing project**.
4. Select your repository.
5. Netlify will automatically detect the configuration from `netlify.toml`:
   - **Build command**: `npm run build`
   - **Publish directory**: `dist`
   - **Functions directory**: `netlify/functions`
6. Click **Deploy site**.

### Method 2: Netlify CLI

1. Install Netlify CLI globally:
   ```bash
   npm install -g netlify-cli
   ```
2. Login and deploy:
   ```bash
   netlify login
   netlify deploy --prod
   ```

## 🔑 Configuring Environment Variables in Netlify

To configure your API keys in Netlify:

1. In the Netlify Dashboard, navigate to your site.
2. Go to **Site configuration** > **Environment variables**.
3. Click **Add a variable** (or **Import from .env**).
4. Add the following variables:

| Variable Name | Required | Description |
| :--- | :---: | :--- |
| `GEMINI_API_KEY` | **Yes** (for AI Guide) | Google Gemini API key for the server-side AI Help Assistant. Get it free at [Google AI Studio](https://aistudio.google.com/app/apikey). |
| `VITE_FIREBASE_API_KEY` | Optional | Firebase Web API Key for live cloud synchronization. |
| `VITE_FIREBASE_AUTH_DOMAIN` | Optional | Firebase Auth Domain (`project-id.firebaseapp.com`). |
| `VITE_FIREBASE_PROJECT_ID` | Optional | Firebase Project ID. |
| `VITE_FIREBASE_STORAGE_BUCKET` | Optional | Firebase Storage Bucket (`project-id.appspot.com`). |
| `VITE_FIREBASE_MESSAGING_SENDER_ID` | Optional | Firebase Cloud Messaging Sender ID. |
| `VITE_FIREBASE_APP_ID` | Optional | Firebase Web Application ID. |
| `VITE_FIREBASE_FIRESTORE_DATABASE_ID` | Optional | Specific Firestore database ID if using a named database. |

5. Trigger a redeploy (**Deploys** > **Trigger deploy** > **Deploy site**) to apply changes.

## 🔄 Updating and Redeploying

When making updates in the future:
1. Make code modifications locally.
2. Verify the production build:
   ```bash
   npm run build
   ```
3. Commit and push to Git:
   ```bash
   git add .
   git commit -m "Add new family messaging features"
   git push origin main
   ```
4. Netlify will automatically build and publish the latest version with zero downtime.
